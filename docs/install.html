Flash CYD Secure OS

This page flashes the firmware directly from your browser over USB. No software install needed — just Chrome or Edge.

Step 1. Plug your ESP32-2432S028 (CYD) into this computer with a USB-C data cable (not a charge-only cable).
Step 2. Click the button below, then pick the CYD's serial port when your browser asks.
Your browser doesn't support this. Please open this page in Google Chrome or Microsoft Edge on a desktop computer (not mobile — WebSerial isn't available there yet). This page needs to be served over HTTPS for this to work (GitHub Pages does this automatically).
If nothing shows up when picking a port: install the CP2102/CH340 USB driver for your OS (search "CP2102 driver" or "CH340 driver" — whichever chip your CYD board uses, printed near the USB port) and reconnect.
Step 3. Follow the on-screen prompts (Install → it erases and writes the new firmware → done). The device reboots into CYD Secure OS automatically.

This page is built by the GitHub Actions workflow in this repo, which compiles the firmware for you every time the code changes — you never need PlatformIO or a compiler installed locally.
